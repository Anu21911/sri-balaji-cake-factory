## 3. Permanent 24/7 Cloud Deployment (e.g., Render.com)

If you would like the application to run permanently on the cloud even when your laptop is turned off:

### Option A: Free Deployment on Render.com (Recommended)
1. **Push your code to GitHub**:
   - Create a free account at [GitHub.com](https://github.com).
   - Create a new repository named `sri-balaji-cake-factory`.
   - In your project folder terminal, link and push:
     ```bash
     git remote add origin https://github.com/YOUR_USERNAME/sri-balaji-cake-factory.git
     git branch -M main
     git push -u origin main
     ```
2. **Deploy on Render**:
   - Go to [Render.com](https://render.com) and sign in with GitHub.
   - Click **New +** -> **Blueprint**.
   - Select your `sri-balaji-cake-factory` repository.
   - Render automatically detects `render.yaml` (which is already configured in this repository).
   - Click **Apply**.
   - In 2-3 minutes, your live production website will be live at `https://sri-balaji-cake-factory.onrender.com`!

### Option B: Railway.app (1-Click Deployment)
1. Go to [Railway.app](https://railway.app).
2. Select **New Project** -> **Deploy from GitHub repo**.
3. Select `sri-balaji-cake-factory`.
4. Railway will automatically build and assign a free custom domain (e.g. `sri-balaji-cake-factory.up.railway.app`).
